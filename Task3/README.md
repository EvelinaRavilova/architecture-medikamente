# Оценка Data Encryption at Rest and In Transit

| Данные | В чём необходимость защиты | Инструменты защиты |
| ------ | -------------------------- | ------------------ |
| Персональные данные | Соблюдение законодательства 152-ФЗ, GDPR, CCPA, несоблюдение приводит к финансовым и репутационным рискам | At Rest: Шифрование БД алгоритмом AES-256;<br>In Transit: TLS 1.3;<br>Контроль доступа RBAC/ABAC;<br>Динамическое маскирование в UI. |
| Медицинские данные | Соблюдение законодательства 323-ФЗ ст. 13, несоблюдение приводит к финансовым и репутационным рискам | At Rest: Шифрование БД алгоритмом AES-256;<br>In Transit: TLS 1.3, для API - mTLS;<br>Контроль доступа RBAC/ABAC. |
| Финансовые данные | Соблюдение PCI DSS compliance, несоблюдение приводит к финансовым и репутационным рискам | TLS 1.3, токенизация данных |
| Учетные данные | Для устранения рисков несанкционированного доступа, приводящим к репутационным рискам | At Rest: хэширование паролей (bcrypt);<br>In Transit: TLS 1.3;<br>MFA. |
| Данные аналитики | Соблюдение законодательства 152-ФЗ, GDPR, CCPA, несоблюдение приводит к финансовым и репутационным рискам |  At Rest: Шифрование БД алгоритмом AES-256;<br>In Transit: TLS 1.3;<br>Контроль доступа RBAC/ABAC;<br>Анонимизация (clickhouse-obfuscator) |
